# README - Sistema de Gerenciamento Ferroviário

## Proposta do Sistema

O projeto tem como proposta o desenvolvimento de um sistema de gerenciamento ferroviário voltado para o controle e monitoramento de trens, linhas, rotas e sensores. O sistema permitirá que administradores realizem o cadastro e gerenciamento das informações, enquanto os usuários terão acesso à página de visualização dos dados e monitoramentos disponíveis.

Os sensores serão utilizados para acompanhar informações importantes dos trens, como velocidade, desempenho e possíveis falhas, permitindo um maior controle operacional e análise do funcionamento da malha ferroviária.

---

## Objetivos do Projeto

* Desenvolver um sistema organizado para gerenciamento ferroviário;
* Permitir o cadastro e controle de trens, rotas e sensores;
* Monitorar informações em tempo real relacionadas ao desempenho dos trens;
* Facilitar a visualização de dados pelos usuários;
* Gerar relatórios para análise de desempenho e funcionamento do sistema.
